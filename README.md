# Reconstruction —— 星图识别（重构版）


## 流水线

```
照片
  │ ① 星点检测：亮区二值化 → 连通域质心 → 去重（按亮度降序）
  ▼
像素坐标 (x, y)
  │ ② 针孔相机模型：像素 → 单位方向向量（主点取图像中心，光轴沿 +z）
  ▼
照片星单位向量 (N, 3)
  │ ③ 与 ≤3 等星表构建的「星对哈希库」做三角形匹配
  │     枚举照片三角形 → 每条边查角距离桶 → 三边首尾闭合 → 投票
  ▼
照片星 → HIP 的投票映射
  │ ④ Kabsch 全局验证：求最优旋转，鲁棒剔除离群点（中位数 + 3σ）
  ▼
一致的旋转矩阵 R
  │ ⑤ 扩展匹配：全部照片星经 R 投影到天球，在 ≤6 等星表中找最近邻
  ▼
完整映射
  │ ⑥ 在原图上标注 HIP 编号
  ▼
output/matched_result.jpg
```

## 算法原理

三角形由三条边的角距离唯一确定（忽略镜像）。核心思想与原项目一致，但实现更高效、对应关系更严谨：

1. **建库**：对标准星表中所有星对计算角距离，按桶号 `round(角距离/0.01°)` 存入哈希表。每个星对同时存 `(a,b)` 和 `(b,a)` 两个方向。
2. **查表**：枚举照片中最亮前 40 颗星的所有三角形，对每条边按角距离查桶（含左右 ±5 个邻桶吸收噪声）。
3. **闭合投票**：若三条边的候选星对能首尾相接（`(a,b),(b,c),(c,a)`），说明照片三角形与该标准星三元组一致，为三颗照片星各投一票。这样投票天然带正确的星与星对应关系（原项目是乱序投票，对应关系不可靠）。
4. **全局验证**：对投票结果求 Kabsch 最优旋转；个别错误投票会带偏最小二乘拟合，因此先用「中位数 + 3σ」鲁棒阈值剔除离群点，再重拟合直至收敛。
5. **扩展匹配**：用收敛后的旋转矩阵把全部照片星投影到天球坐标系，在更全的 6 等星表（约 5000 颗）中找最近邻（角距 < 0.5°），把剩余星点也识别出来。

## 与原实现的差异

| 环节 | 原项目 | 重构版 | 收益 |
| --- | --- | --- | --- |
| 哈希库 | 三角形哈希：C(n,3) ≈ 83 万个条目（n=172） | 星对哈希：C(n,2) ≈ 1.5 万个条目 | 建库 O(n³) → O(n²) |
| 查桶 | 每三角形遍历 (2r+1)³ = 1331 个三维邻桶 | 每条边查 (2r+1) = 11 个一维桶，共 33 次 | 查询量降约 40 倍 |
| 投票 | 候选三元组乱序，星与边无对应关系 | 有序星对 + 三边闭合，投票对应准确 | 匹配更可靠 |
| 全局验证 | 无 | Kabsch 旋转对齐 + 鲁棒离群剔除 | 自动剔除误匹配 |
| 扩展识别 | 无 | 6 等星表最近邻补充 | 识别更完整 |
| 坐标换算 | 逐星 Python 循环 | NumPy 向量化 | 快且简洁 |
| 图像尺寸 | 硬编码 4000×1600 | 从图像实际读取 | 换照片不用改代码 |
| 调试中间图 | 固定写入 Trash/ | 可开关，默认关闭 | 目录干净 |

实测（Antares.jpg，26mm 焦距 / 8.5µm 像素，2025 年数据）：21 颗星全部匹配，Kabsch 平均残差约 0.08°，单张照片匹配耗时 < 1 秒（不含首次建库）。

## 配置说明（config.py）

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `DETECTION_THRESHOLD` | 252 | 亮区二值化阈值，越小检测到的星越多（也越容易混入噪点） |
| `DETECTION_MIN_DISTANCE` | 10 | 两星最小像素间距 |
| `DETECTION_SAVE_DEBUG` | False | 是否保存预处理中间图到 output/debug/ |
| `FOCAL_MM` / `PIXEL_SIZE_MM` | 26.0 / 0.0085 | 相机焦距与像素尺寸，**匹配失败时优先调这里** |
| `BIN_WIDTH_DEG` | 0.01 | 角距离分桶宽度（度） |
| `NEIGHBOR_BINS` | 5 | 查桶邻域，吸收测量噪声 |
| `PHOTO_TOP_N` | 40 | 参与投票的照片最亮星数 |
| `MIN_VOTES` | 2 | 投票保留阈值 |
| `VERIFY_RESIDUAL_DEG` | 1.0 | 验证残差硬阈值（度） |
| `EXTEND_RESIDUAL_DEG` | 0.5 | 扩展匹配最近邻角距阈值（度） |
| `ENABLE_EXTENSION` | True | 是否用 6 等星表做扩展匹配 |

## 常见问题

**一个都匹配不上？** 大概率是相机参数不准。角距离由 `FOCAL_MM / PIXEL_SIZE_MM` 决定，试着微调 `FOCAL_MM`（比如 20~35mm 之间）或 `PIXEL_SIZE_MM`，直到"平均残差"降到 0.2° 以下。

**检测到的星太少？** 调低 `DETECTION_THRESHOLD`（例如 200），再不行看 `DETECTION_SAVE_DEBUG=True` 产生的中间图。

**改了 `BIN_WIDTH_DEG` 没生效？** 哈希库缓存文件名包含桶宽，删除 `cache/pair_hash_db_*.pkl` 重建即可。

**换了相机或镜头？** 主点默认取图像中心；若有明显偏心，可在 `camera.py` 中把 `pixels_to_unit_vectors` 扩展为接受主点参数。
